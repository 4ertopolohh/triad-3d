# Оптимизация экспорта — TASK-060

В диалоге экспорта есть явная опция «Оптимизировать копию экспорта». Она не меняет Project, историю или исходные ресурсы. Тяжёлая обработка идёт в прерываемых Workers; ошибка не выдаёт частично подготовленный пакет.

- Геометрия: точная сварка одинаковых position/normal/UV/color, Meshopt simplifyWithAttributes с LockBorder отдельно для каждой материальной группы, удаление неиспользуемых вершин. Цель — половина индексов, относительный бюджет ошибки 0,01 с весами атрибутов. Швы могут препятствовать сокращению. Пустые CSG-результаты сохраняются.
- Сжатие: Meshopt vertex/index-sequence streams в base64 `geometry.json`, декодер в экспортном компоненте. Float32-атрибуты и порядок индексов проходят roundtrip. Сжатые геометрии не дублируются в `model.json`; runtime-узлы используют `meshSource: {kind: "baked"}`, без исходных editable-массивов. Это производный runtime-контракт, не нативный документ проекта. Зависимость meshoptimizer 1.1.1 и MIT-лицензия включены. Декодер добавляет размер runtime; выгода всего ZIP зависит от сцены.
- Цветовые PNG/JPEG/WebP карты baseColor/emissive: до 2048 px, WebP quality 0,9. Если файл не уменьшается или кодер отсутствует, сохраняется исходник. HDR/EXR, GLB и любые ресурсы, используемые одновременно как числовая PBR-карта, не перекодируются.
- Отчёт: треугольники, геометрический JSON и сжатый поток, размер изображений, RGBA RMSE/max относительно уже масштабированного исходника. Это не гарантия визуальной эквивалентности; downscale-потеря в RMSE не включена. Оригинальные геометрия/текстуры сохранены отдельно для сравнения Max слева и результата справа.

Бюджеты: 500000 вершин, 64 MiB индексов; producer и decoder согласованы. Компрессия не меняет авторитетные инварианты и не добавляет хранилище сессии.

Проверено в браузере через реальные Workers и WebP-кодер: сфера 3968→1984 треугольника, JSON 325085→162401 байт, Meshopt/base64 31989 байт; цветовая карта 155744→12190 байт, RMSE 1,19/255, max 9/255. Сравнение и метрики: `qa/optimization.png`, `qa/optimization.json`; воспроизводимый стенд `qa/optimization.html`. Чистый build обычного и сжатого экспортов включён в `npm run export:production-check` и CI. Ограничения: исходные GLB внутри проекта не упрощаются; normal/roughness/metalness/bump не перекодируются с потерями.

API: [официальная документация meshoptimizer](https://github.com/zeux/meshoptimizer/blob/master/js/README.md).
