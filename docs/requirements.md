# Requirements

Stages: `MVP` required for first useful release; `NEXT` deferred.

## Проект и рабочая сессия

### FR-001 — Создать проект [MVP]
- Behavior: Команда «Новый проект» создаёт документ с одним корневым Model и одной Scene, системной камерой и нейтральным окружением.
- Failure: Если есть несохранённые изменения, показать предупреждение до сброса.
- Acceptance: Корректно открывается пустой редактируемый проект.

### FR-002 — Два режима редактирования [MVP]
- Behavior: Переключение «Модель / Сцена» сохраняет selection и общую модель данных; режим Модель меняет геометрию, режим Сцена — окружение и экземпляры.
- Failure: При недоступном объекте показать состояние без потери изменений.
- Acceptance: Переключение не дублирует геометрию и сохраняет изменения.

### FR-003 — Одно основание модели и одна сцена [MVP]
- Behavior: Каждый проект содержит одну основную редактируемую модель и ровно одну сцену с её экземплярами и вспомогательными объектами.
- Failure: Запретить создание второй независимой корневой модели в том же проекте; позволить составные подгруппы.
- Acceptance: Дерево проекта соблюдает инвариант 1 Model / 1 Scene.

### FR-004 — Выбор и трансформации [MVP]
- Behavior: Click/raycast выбирает объект; gizmo задаёт перенос, вращение и масштаб численно или мышью в local/world координатах.
- Failure: Скрытые/заблокированные узлы не редактируются; неверные числа не применяются.
- Acceptance: Численные и визуальные изменения совпадают.

### FR-005 — Иерархия и группировка [MVP]
- Behavior: Дерево поддерживает parent/child, группы, именование, раскрытие, перенос узлов и сохранение локальных преобразований.
- Failure: Запрещены циклические зависимости и удаление корня модели.
- Acceptance: Перегруппировка не вызывает непреднамеренных скачков позиции.

### FR-006 — Множественное выделение [MVP]
- Behavior: Shift/Ctrl выделяют группу объектов, общие свойства применяются пакетной командой к выбранному набору.
- Failure: Несовместимое свойство отображается как смешанное; команда транзакционна.
- Acceptance: Все целевые узлы получают изменение либо откат.

### FR-007 — Видимость и блокировка [MVP]
- Behavior: На узле доступны flags visible и locked, переключаемые из дерева и инспектора.
- Failure: Блокировка наследуется на потомков для редактирования.
- Acceptance: Скрытые и заблокированные объекты не изменяются инструментами.

### FR-008 — Сессионное состояние [MVP]
- Behavior: В памяти вкладки живут документ, временные снимки, undo/redo и dirty-state; persistent browser storage выключен.
- Failure: Закрытие/refresh уничтожают несохранённое; перед unload включать best-effort предупреждение.
- Acceptance: После обновления нет восстановленного проекта.

### FR-009 — Undo/Redo и версии сеанса [MVP]
- Behavior: Команды образуют обратимые транзакции; хранить дельты и ограничивать память умной компактификацией, при этом не вводить малый произвольный предел количества шагов.
- Failure: Отмена сбойной операции не меняет историю; контрольные точки только на время вкладки.
- Acceptance: 100 последовательных операций корректно отменяются и воспроизводятся.

### FR-010 — Операция «Сохранить проект» [MVP]
- Behavior: Явное сохранение производит самодостаточный TRIAD3D-архив с данными и ресурсами через файловый диалог/загрузку.
- Failure: Не писать файлы автоматически на диск; ошибки сериализации объяснять.
- Acceptance: Перезапущенный редактор открывает сохранённый файл без сети.

### FR-011 — Загрузка проекта [MVP]
- Behavior: Системный диалог загружает поддерживаемые форматы проекта, проверяет manifest и мигрирует версии данных в памяти.
- Failure: Неподдерживаемую версию не открывать молча, показывать причину и сохранять текущий проект.
- Acceptance: Round-trip модели, материалов, анимаций и ресурсов без потерь.

## Геометрия и модификаторы

### FR-012 — Библиотека примитивов [MVP]
- Behavior: Добавление cube/sphere/torus/cylinder/cone/plane и базовых форм с управляемым размером и сегментами.
- Failure: Невалидные размеры и чрезмерное число сегментов предупреждаются.
- Acceptance: Созданный примитив отображается и меняется параметрически.

### FR-013 — Редактирование граней и вершин [MVP]
- Behavior: Режимы vertex/edge/face поддерживают выделение и базовые перенос/масштаб/выдавливание с защитой корректности сетки.
- Failure: Не поддерживать произвольные действия, если они приводят к разрушению топологии; показывать причину.
- Acceptance: Пользователь меняет локальную геометрию без кода.

### FR-014 — Булево вычитание отверстий [MVP]
- Behavior: Boolean subtract обрабатывает замкнутые тела через вычислительный сервис; исходный cutter и параметры остаются в стеке.
- Failure: При неманифолдных входах отклонять команду и сохранять исходную сетку.
- Acceptance: Отверстия остаются настраиваемыми после сохранения.

### FR-015 — Булево объединение/пересечение [MVP]
- Behavior: Union/intersect объединяют и пересекают допустимые solid meshes как недеструктивную операцию.
- Failure: Предупреждать при пустом результате или непригодной сетке.
- Acceptance: Результат воспроизводим при повторной оценке.

### FR-016 — Процедурные массивы [MVP]
- Behavior: Linear/radial array создаёт повторения по шагу, оси, углу, количеству и offset, сохраняя исходную деталь.
- Failure: Не создавать нулевые шаги или бесконечные цепочки зависимостей.
- Acceptance: Изменение одной детали обновляет экземпляры.

### FR-017 — Симметрия и зеркалирование [MVP]
- Behavior: Mirror по одной/нескольким локальным плоскостям с контролем pivot и объединения шва.
- Failure: При невозможности сшивания выдавать предупреждение, не менять исходник.
- Acceptance: Симметричные отверстия синхронно обновляются.

### FR-018 — Базовые деформации [MVP]
- Behavior: Bend/twist/taper/bevel по параметрам с предсказуемым порядком применения.
- Failure: Слишком агрессивная деформация не портит исходную сетку.
- Acceptance: Настройка модификатора меняет вычисленный результат.

### FR-019 — Стек модификаторов [MVP]
- Behavior: У каждого mesh-узла ordered modifier stack с параметрами, enabled, version и action reorder/remove.
- Failure: Изменение не должно ломать связи последующих модификаторов; ошибка — rollback.
- Acceptance: Отключение модификатора восстанавливает предыдущий результат.

### FR-020 — Переиспользуемые составные объекты [MVP]
- Behavior: Группу можно представить единым управляемым объектом, сохранив вложенное дерево и внутренние идентификаторы.
- Failure: Flatten не должен выполняться скрытно.
- Acceptance: После раскрытия внутренние детали доступны без потерь.

### FR-021 — Кисти по поверхности [MVP]
- Behavior: Видимые кисти Paint/Material/Displace с radius, strength, shape, fill и symmetry используют hit-point по BVH.
- Failure: Объект без нужного UV/топологии получает подсказку о доступном режиме.
- Acceptance: Превью под курсором совпадает с фактическим действием.

### FR-022 — Кисть процедурных деталей [NEXT]
- Behavior: Brush stamps добавляют отверстия, шипы, углубления и повторения вдоль поверхности и симметрии через редактируемые генераторы.
- Failure: Ограничения самопересечения и дорогого re-meshing фиксируются явно.
- Acceptance: Параметры любого stamp редактируются после нанесения.

### FR-023 — Расширенные генераторы форм [NEXT]
- Behavior: Генераторы решёток, панелей, механических вырезов и художественных скульптур имеют seed и регулируемые параметры.
- Failure: Каждый генератор имеет границы применимости и инструмент предпросмотра.
- Acceptance: Из одинаковых параметров и seed выходит одинаковая модель.

### FR-024 — Точные численные параметры [MVP]
- Behavior: Координаты и размеры хранятся в условных 3D единицах, UI поддерживает float-ввод и ограничение точности.
- Failure: NaN/Infinity отвергаются; масштаб с отрицательным детерминантом требует нормализации.
- Acceptance: Повторный ввод числа обеспечивает стабильную геометрию.

### FR-025 — Контроль качества сетки [MVP]
- Behavior: Проверки замкнутости, нормалей, degenerate faces и self-intersection применяются там, где требуется операцией.
- Failure: При угрозе повреждения отменять только операцию и сохранять сообщение.
- Acceptance: Ошибочная CSG не меняет текущий документ.

### FR-026 — Оптимизация геометрии [NEXT]
- Behavior: Доступны weld, simplify, instancing/batching и снижение детализации как отдельные копии для экспорта.
- Failure: Предупреждать о потере деталей; оригинал не модифицируется.
- Acceptance: Сравнение размера до/после доступно пользователю.

## Материалы, освещение и ресурсы

### FR-027 — PBR-материалы [MVP]
- Behavior: Поддержка baseColor, metalness, roughness, emissive, transparency/transmission, ior, clearcoat, normal/bump и envIntensity согласно рендереру.
- Failure: Неподдерживаемые свойства в конкретном режиме помечаются.
- Acceptance: Chrome, glass, stone выглядят различимо при заданном окружении.

### FR-028 — Галерея материалов [MVP]
- Behavior: Категории metal/glass/plastic/stone/abstract с превью на эталонной сфере и поиском.
- Failure: Ресурсы отсутствующего пресета загружаются по запросу с прогрессом.
- Acceptance: Пресет назначается выбранному объекту одним действием.

### FR-029 — Drag & drop материала [MVP]
- Behavior: Перетаскивание из галереи на модель назначает materialId выделенному material slot/mesh.
- Failure: Drop на невалидную область не меняет материал.
- Acceptance: Смена материала записывается в Undo.

### FR-030 — Настройка свойств материала [MVP]
- Behavior: Слайдеры и точные поля с разумными ограничениями, grouped basic/advanced.
- Failure: Неверные значения подсвечиваются; reset property восстанавливает пресет.
- Acceptance: Изменение preview и результата синхронизировано.

### FR-031 — Загрузка изображений и карт [MVP]
- Behavior: Импорт PNG/JPEG/WebP/HDR/EXR по проверенным декодерам с assets manifest, hash, size, colorspace.
- Failure: Неизвестные MIME, битые и очень крупные файлы отклоняются.
- Acceptance: Карта материала переносится при сохранении проекта.

### FR-032 — UV и проекции [MVP]
- Behavior: Для примитивов генерировать UV; для кистей применять planar/box/triplanar mapping там, где допустимо.
- Failure: При отсутствии UV предложить проекционный mapping или предупредить.
- Acceptance: Текстура остаётся привязанной к поверхности после reopen.

### FR-033 — Процедурные текстуры [MVP]
- Behavior: Noise, grain, scratches, brushed metal, marble, stone relief управляются seed/scale/intensity/direction и могут быть baking в карты.
- Failure: Параметры хранятся без зависимости от внешней сети.
- Acceptance: Один preset воспроизводит одинаковую фактуру.

### FR-034 — Рельеф и микродетали [MVP]
- Behavior: Normal/bump/roughness maps меняют внешний вид поверхности с настраиваемой силой.
- Failure: UI различает визуальный рельеф и реально изменённую геометрию.
- Acceptance: Рельеф виден при вращении света/модели.

### FR-035 — Свет и HDRI [MVP]
- Behavior: Одна Scene содержит directional/point/area-like lights где поддерживаются и environment с управляемыми интенсивностью/поворотом.
- Failure: Отсутствующие ресурсы не блокируют работу, включается нейтральный свет.
- Acceptance: Переключение HDRI видимо меняет отражения хрома.

### FR-036 — Камера и фон [MVP]
- Behavior: Orbit/pan/zoom, перспективная камера сцены и настройка background/toneMapping/exposure.
- Failure: Не допускать NaN камеры, clipping и потери объёма из видимости без Reset view.
- Acceptance: Пользователь возвращает сцену командой Fit/Reset.

### FR-037 — Три уровня предпросмотра [MVP]
- Behavior: Draft/Quality/Final управляют ресурсом и эффектами без изменения исходного проекта.
- Failure: При недоступном WebGPU использовать проверенный fallback и список ограничений.
- Acceptance: Переключение качества не меняет модель/материалные параметры.

### FR-038 — Фотореалистичный финальный рендер [NEXT]
- Behavior: Неинтерактивный режим улучшенной визуализации с возможностью накопления сэмплов; сохранять метаданные рендер-профиля.
- Failure: Если path tracing недоступен, объяснить причину и оставить raster final.
- Acceptance: Качество увеличивается при длительном рендере, отмена доступна.

### FR-039 — Пользовательские ресурсы/пакеты [NEXT]
- Behavior: Импорт и экспорт наборов текстур, материалов, HDRI и пресетов из архивов с версиями и лицензиями.
- Failure: Конфликты имён разрешать через ID, не перезаписывать молча.
- Acceptance: Несколько пресетов загружаются одним архивом.

## Анимация и временная шкала

### FR-040 — Ключевые кадры [MVP]
- Behavior: Для узла задаются keyframes position/rotation/scale и поддерживаемые свойства на времени t (секунды).
- Failure: Дубликаты на одном канале/времени имеют определённое правило replace.
- Acceptance: Анимация соответствует расставленным ключам.

### FR-041 — Редактирование start/end точек [MVP]
- Behavior: Перемещение объекта в двух временах создаёт/изменяет ключи, пользователь выбирает interpolation из пресетов.
- Failure: При движении камеры нельзя случайно создать ключ модели.
- Acceptance: Предпросмотр проходит через начальную и конечную точки.

### FR-042 — Таймлайн [MVP]
- Behavior: Панель воспроизведения и tracks отдельных объектов с drag keyframe, snapping, zoom, mute/solo и loop markers.
- Failure: При скрытой панели playback остаётся доступным из toolbar.
- Acceptance: Пользователь управляет длительностью и ключами без кода.

### FR-043 — Кривые ускорения [MVP]
- Behavior: Graph editor управляет easing/Bezier handles для ключевых пар, предусмотрены линейная и плавная интерполяции.
- Failure: Некорректные контрольные точки нормализовать или отклонять.
- Acceptance: Изменённая кривая меняет скорость без смены конечной точки.

### FR-044 — Петля без скачка [MVP]
- Behavior: Для periodic channels проверять равенство начального/конечного состояния и согласованность касательных/скоростей, предоставлять align-loop action.
- Failure: Интерактивные возмущения не гарантируют бесшовность сами по себе.
- Acceptance: Автоматический тест loop comparison в t=0 и t=T проходит.

### FR-045 — Замедленное воспроизведение [MVP]
- Behavior: Playback rate 0.1×...1×...2× влияет на preview, но не на экспортируемые key times.
- Failure: Не допускать отрицательной скорости без обратного playback.
- Acceptance: При 0.25× время playback идёт в четыре раза медленнее.

### FR-046 — Пресеты движения [MVP]
- Behavior: Spin, orbit, translate, bounce-like easing, oscillation и reveal доступны с параметрами и импортом в animation stack.
- Failure: Preset не перезаписывает существующие каналы без явного действия.
- Acceptance: Одному объекту можно назначить пресет в 2 клика.

### FR-047 — Групповая анимация [MVP]
- Behavior: Трансформации родительской группы учитываются вместе с локальной анимацией дочерних объектов.
- Failure: Циклические родительские связи запрещены.
- Acceptance: Вращение группы и движение детали визуально суммируются.

### FR-048 — Совмещение каналов [NEXT]
- Behavior: Animation graph смешивает независимые каналы и поддерживает priority, additive vs override и blend weights.
- Failure: Конфликтующие эффекты имеют предсказуемое разрешение.
- Acceptance: Вращение и магнит работают вместе без скачка.

### FR-049 — Курсорное притяжение [NEXT]
- Behavior: Proximity event локализует ближайшие объекты и добавляет временное displacement с falloff/release.
- Failure: Удаление курсора плавно возвращает объект к базовому движению.
- Acceptance: Возврат не сбрасывает фазу базовой анимации.

### FR-050 — Конструктор событий [NEXT]
- Behavior: Event→Condition→Action с предварительно типизированными блоками pointer/click/time/proximity и безопасными параметрами.
- Failure: Произвольный JS не выполняется в DSL; циклы и недопустимые зависимости диагностируются.
- Acceptance: Созданное правило сериализуется и работает после TSX-экспорта.

### FR-051 — Пресеты интерактивности [NEXT]
- Behavior: Magnet, click-toggle, hover-reveal, orbit-follow, pulse предлагаются с параметрами и совместимыми событиями.
- Failure: Конфликт c physics/other rules диагностируется.
- Acceptance: Пресет видим в инспекторе и полностью редактируется.

### FR-052 — Коллизии и отталкивание [NEXT]
- Behavior: Для выбранных объектов доступны colliders, mass, restitution, enable; физический слой рассчитывает контакты.
- Failure: Не обещать непересечения при всяком kinematic движении; нужные случаи решать отдельным constraint/avoidance.
- Acceptance: Два поддерживаемых dynamic тела корректно отскакивают.

### FR-053 — Стабильные точки вращения [MVP]
- Behavior: Pivot задаёт ось orbit/spin отдельно от геометрического центра, сохраняется в файле и TSX.
- Failure: Изменение pivot не должно разрушать текущую позицию без явного apply.
- Acceptance: Фигура вращается вокруг выбранного pivot.

## Сцена, экземпляры и пользовательский опыт

### FR-054 — Экземпляры основной модели [NEXT]
- Behavior: В Scene добавляются linked instances одной Model; экземпляры используют общую геометрию и дефолтные материалы.
- Failure: Копии получают собственные overrides только при включении соответствующего режима.
- Acceptance: Добавление 20 копий не клонирует все исходные данные.

### FR-055 — Контроль распространения изменений [NEXT]
- Behavior: Linked update по умолчанию не применяет новый model revision к уже размещённым копиям, пока пользователь не подтвердит apply/sync.
- Failure: Показать какие copies устарели; preview перед apply.
- Acceptance: Изменение исходной модели не меняет копии без подтверждения.

### FR-056 — Overrides экземпляров [NEXT]
- Behavior: Per-instance material/animation overrides включаются явным действием, остальные свойства наследуются.
- Failure: Reset overrides возвращает общий материал и анимацию.
- Acceptance: Изменение материала одной копии не затрагивает другие.

### FR-057 — Панель объектов [MVP]
- Behavior: Слева дерево, поиск, фильтры, групповые операции, hide/lock, drag reorder.
- Failure: На больших деревьях использовать виртуализацию.
- Acceptance: Выбор из дерева синхронен с viewport.

### FR-058 — Инспектор свойств [MVP]
- Behavior: Справа контекстные basic группы и раскрываемый advanced со смешанными значениями для multi-select.
- Failure: Недоступное поле объясняет причину отключения.
- Acceptance: Редактирование не теряет фокус без необходимости.

### FR-059 — Контекстные подсказки [MVP]
- Behavior: На hover инструмент показывает назначение, значения и короткую демонстрацию сложного действия без передачи файлов на сервер.
- Failure: Анимация подсказки останавливается при prefers-reduced-motion.
- Acceptance: Новичок может выполнить основной сценарий без документации.

### FR-060 — Горячие клавиши [MVP]
- Behavior: Ctrl+Z/Y, Ctrl+S (экспорт файла), F fit, Delete, Esc, G/R/S при свободных полях; help shortcut palette.
- Failure: В поле ввода горячие клавиши не должны нарушать набор текста.
- Acceptance: Клавиатура выполняет операции, соответствующие UI.

### FR-061 — Только ПК [MVP]
- Behavior: Editor поддерживает desktop mouse+keyboard; на неподдерживаемых узких viewport выдаётся корректное сообщение, не сломанный UI.
- Failure: Не заявлять полную мобильную поддержку редактора.
- Acceptance: При ширине менее порога выводится информативный экран.

### FR-062 — Ошибки с восстановлением [MVP]
- Behavior: Сбой отдельного Worker/CSG/material compilation изолируется и не ломает текущий документ.
- Failure: Каждая операция возвращает понятный error code и rollback.
- Acceptance: После ошибки возможна следующая корректная операция.

### FR-063 — Прогресс тяжёлой операции [MVP]
- Behavior: Долгий вычислительный job блокирует редактирование, показывает action, progress если доступен, cancel если поддерживается.
- Failure: При невозможности процентов выводить неопределённый прогресс.
- Acceptance: После success/failure/cancel UI разблокирован.

## Импорт и экспорт

### FR-064 — Импорт GLB/GLTF [MVP]
- Behavior: GLTFLoader поддерживает геометрию, материалы и совместимые clip-анимации; импорт создаёт адаптированный узел модели.
- Failure: Unsupported extensions/invalid assets маркировать и не портить исходный документ.
- Acceptance: Тестовый GLB успешно добавлен в редактор.

### FR-065 — Импорт OBJ и других форматов [NEXT]
- Behavior: Через отдельные адаптеры импортировать поддерживаемые форматы с документированной потерей материалов/анимаций.
- Failure: Показывать матрицу совместимости перед применением.
- Acceptance: OBJ читается с предсказуемыми ограничениями.

### FR-066 — Анализ TSX/JSX/HTML без исполнения [NEXT]
- Behavior: AST parser читает поддерживаемые декларативные конструкции Three.js/R3F и извлекает статическую сцену; режим dry-run показывает результат.
- Failure: Не выполнять arbitrary JS, eval, user imports/network; частичный импорт с подробным отчётом.
- Acceptance: Неподдерживаемые элементы перечислены, доверие не требуется.

### FR-067 — Импорт частично поддерживаемого кода [NEXT]
- Behavior: Формировать supported/unsupported/warning записи с range, type, cause, skip/replace actions.
- Failure: Не утверждать 100% конверсию; сохранять оригинал только как вложение по явному согласию.
- Acceptance: Пользователь видит что потеряно до принятия.

### FR-068 — Экспорт React TSX [MVP]
- Behavior: Генератор создаёт компонент, валидируемые props, ресурсы и runtime модуль анимации с нужными deps и примером использования.
- Failure: Не выдавать библиотечно зависимую сцену за self-contained один файл.
- Acceptance: Сгенерированный компонент собирается в проверочном Vite React проекте.

### FR-069 — Экспорт одним копируемым фрагментом [MVP]
- Behavior: Для простого asset-free результата показать TSX-код в копируемом блоке, для ресурсов — ZIP и инструкции.
- Failure: Если ресурсов/вспомогательных файлов много, честно объяснить предел одного фрагмента.
- Acceptance: Копируемый вариант собирается при указанных deps.

### FR-070 — Экспорт ZIP [MVP]
- Behavior: Пакет содержит TSX, assets, types, README, зависимости и лицензии ресурсов при наличии.
- Failure: Paths относительны; duplicate filenames disambiguate.
- Acceptance: Распакованный пакет интегрируется в чистый React/Vite проект.

### FR-071 — Props-редактирование экспорта [MVP]
- Behavior: Выбранные автором параметры surface/display/time/interaction вынести в typed props с default values.
- Failure: Не экспортировать runtime-secrets и неподдерживаемые значения.
- Acceptance: Props влияют на соответствующие свойства после сборки.

### FR-072 — Экспорт GLB/GLTF [NEXT]
- Behavior: Геометрия и совместимые glTF PBR материалы и clip-анимации экспортируются стандартным форматом с матрицей потерь.
- Failure: Rules, arbitrary shaders и interaction logic не сохраняются как runtime semantics.
- Acceptance: GLB открывается независимым загрузчиком без ошибок.

### FR-073 — Профили качества [MVP]
- Behavior: Выбор Max/Balanced/Lite при экспорте создаёт отдельный артефакт, не изменяя редактируемый оригинал.
- Failure: Сильное ухудшение качества предупреждается с preview и сравнением статистики.
- Acceptance: Оригинальный исходник сохраняется без изменений.

### FR-074 — Предупреждения о тяжёлых эффектах [MVP]
- Behavior: Дорогие эффекты и GPU требования выводятся в export preview; предлагаются compatible alternatives.
- Failure: Предупреждение не запрещает оригинал, если он технически реализуем.
- Acceptance: Можно сознательно экспортировать Max без auto-downscale.

### FR-075 — Видеорендер [NEXT]
- Behavior: Поддержка WebM и условно MP4 при доступном browser encoder/WASM, фиксированный шаг по timeline для циклических кадров.
- Failure: Если codec/browser не поддерживаются, показать альтернативу/инструкцию.
- Acceptance: Экспорт 10 секунд даёт корректную длительность и fps.

### FR-076 — Диагностика совместимости веба [NEXT]
- Behavior: Показывать количество draw calls, triangles, compressed/uncompressed texture memory estimates, browser features.
- Failure: Статистика является оценкой, не гарантирует fps.
- Acceptance: Отчёт доступен до экспорта.

## Non-functional requirements

### NFR-001 — Данные только в RAM вкладки [MVP]
- Rule: Не использовать localStorage, IndexedDB, ServiceWorker Cache API для хранения документа или истории; все persistence — только явный пользовательский file export.
- Check: E2E очистка и reload без восстановления.

### NFR-002 — Безопасная загрузка файлов [MVP]
- Rule: Валидация MIME/extension/signature и фактического содержимого, ограничения размера/числа объектов/глубины, отказ от eval и исполнения сценариев в загруженных данных.
- Check: Фазз/negative tests парсеров.

### NFR-003 — Атомарность операций [MVP]
- Rule: Все document mutations через транзакционные команды; ошибки CSG/worker приводят к rollback.
- Check: Инвариант hash документа после отказа.

### NFR-004 — Предсказуемость анимаций [MVP]
- Rule: Одинаковое время и seed при отсутствии внешних воздействий дают одинаковую позу; interpolation/tangent проверяемы.
- Check: Deterministic property tests.

### NFR-005 — Ограничение памяти [MVP]
- Rule: Предупреждение до исчерпания памяти, LRU вычисленной геометрии/texture cache, отсутствие систематических утечек при циклах open/close.
- Check: Heap/GPU профилирование по тестовым сценам.

### NFR-006 — Управляемые блокировки [MVP]
- Rule: В тяжёлой операции редактирование заблокировано, но интерфейс показывает прогресс/Cancel, event loop не должен окончательно зависать.
- Check: E2E job state transition.

### NFR-007 — Визуальный эталон [MVP]
- Rule: Golden scenes содержат metal/glass/stone, HDRI, shadows и фиксированные условия освещения.
- Check: Порог визуального различия документируется для среды CI.

### NFR-008 — Стабильный экспорт [MVP]
- Rule: TSX-пакет должен собираться в чистом React/Vite проекте с указанными зависимостями; GLB roundtrip для поддерживаемых сцен.
- Check: Build harness + smoke render.

### NFR-009 — Прозрачная деградация [MVP]
- Rule: WebGPU/WebGL2 feature detection, явный status, предупреждения о неподдерживаемых эффектах; отсутствие молчаливого пропуска critical features.
- Check: Запуск с forced WebGL fallback.

### NFR-010 — Доступность ПК [MVP]
- Rule: Keyboard navigation панелей, focus visible, contrast, reduced motion для UX chrome, доступные подписи контролов.
- Check: Аудит keyboard/automated a11y.

### NFR-011 — Согласованность экспорта [MVP]
- Rule: Отчёт о несовместимости материалов/свойств, side-by-side preview для профилей экспорта.
- Check: Comparator тестовых случаев.

### NFR-012 — Качество обслуживания [MVP]
- Rule: Ошибки показывают понятный текст на русском и error code; пользователь может отменить и продолжить работу.
- Check: Negative scenario tests.

### NFR-013 — Локальная разработка [MVP]
- Rule: Windows 11, Node/npm и браузер без секретных ключей; один npm install + npm run dev из корня.
- Check: Fresh clone smoke test.

### NFR-014 — Статический деплой [MVP]
- Rule: Vite static build функционирует на GitHub Pages по корректному base URL; внешние файлы доступны при CORS и лицензии.
- Check: Deploy preview smoke.

### NFR-015 — Тесты по риску [MVP]
- Rule: Types/build и критические unit+integration+E2E; avoid redundant whole suite after each small change.
- Check: CI workflow task gates.

### NFR-016 — Безопасные пресеты [NEXT]
- Rule: Сторонние preset packs — данные, не скрипты. Проверка пути архива (zip slip), размера и external URLs.
- Check: Malicious payload smoke.

### NFR-017 — Целевые показатели без выдумок [MVP]
- Rule: До профилирования не обещать конкретные FPS/число полигонов; фиксировать test hardware и сценарии, получать измеримые бюджеты после prototyping.
- Check: Performance baseline report.

### NFR-018 — Лицензии [MVP]
- Rule: Отдельно документировать права на внешние HDRI/texture packs и шрифты Actay/AKONY. Не включать сторонние файлы без подтверждения лицензии.
- Check: License audit release.
