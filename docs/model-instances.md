# Экземпляры модели — TASK-050

В режиме «Сцена» добавьте экземпляр основной модели. Все экземпляры одной версии ссылаются на один сохранённый снимок; редактирование модели не меняет существующие экземпляры. «Просмотреть Sync» показывает количество добавленных, удалённых и изменённых сущностей, затем отдельная кнопка применяет обновление. Sync, добавление, настройки и удаление поддерживают Undo/Redo. Положение, вращение, масштаб, видимость, материал и анимационный override сохраняются при Sync. Если выбранный override-клип удалён из новой модели, сначала сбросьте его.

Снимки входят в ручной архив документа 1.10.0. Старые документы строго проверяются; экземпляры из 1.9 получают общий снимок текущей модели. Единственные Model и Scene остаются прежними. Лимиты: 128 экземпляров и 32 используемых снимка. Неиспользуемые снимки удаляются из документа, но история Undo удерживает прежнее состояние в RAM.

Renderer клонирует только иерархию объектов. Геометрия одного снимка общая даже при разных цветах/материалах. Изменение UV-проекции требует отдельного производного варианта геометрии. Материалы/текстуры учитываются по владельцам; удаление последнего пользователя освобождает ресурсы. Модификаторы вычисляются блокирующей отменяемой задачей. Ошибка/отмена не изменяет документ; повторный запуск предпросмотра повторяет вычисление.

Override материала — сохранённая копия выбранного материала для всех Mesh данного экземпляра; дальнейшее редактирование исходного материала её не меняет. Сброс возвращает материалы снимка. Override анимации выбирает клип снимка, паузу или скорость 0–4. Playback использует абсолютное время и независимое зацикливание; ручное перемещение курсора таймлайна оценивает ограниченное время без wrap.

TSX/ZIP разворачивает снимки в отдельный производный runtime-граф. Исходный документ не меняется. Props выбранного узла применяются ко всем его копиям в снимках. Export geometry сейчас сериализуется для каждой копии; совместное хранение в нативном документе и общий GPU-буфер редактора не означают Meshopt instancing в ZIP. GLB запекает выбранные overrides в один клип: первая последовательность без повторения loop-диапазонов, короткие клипы удерживают конечную позу; это указано в loss report.

Проверки: 20 экземпляров с разными цветами используют одну BufferGeometry; независимая анимация и scrub; проекция на первоначально неназначенном материале; документ migration/roundtrip/Undo/Redo; props в TSX; реальный GLB roundtrip через независимый GLTFLoader. Browser smoke: два куба → изменение Y масштаба модели → просмотр diff → Sync только первого → Undo/Redo → архив → открытие в отдельной сессии, сохранение r2/r1, console errors отсутствуют.
