# OBJ — FR-065

«Импорт OBJ» открывает отдельный диалог. Выбор файла запускает отменяемый Worker; до применения видны число объектов/треугольников и отчёт о потерях. Подтверждение добавляет все группы одной командной транзакцией. Ошибка, отмена или смена проекта не меняют документ. Undo/Redo и ручной native archive сохраняют результат.

| Данные OBJ | Поддержка |
|---|---|
| `v x y z`, `v x y z 1` | Геометрия без изменения координат/масштаба |
| `f` с положительными/отрицательными индексами | Треугольники и выпуклые плоские четырёхугольники |
| `vt u v` | UV с раздельными индексами/швами; неполная UV-группа импортируется без UV с отчётом |
| `o`, `g` | Отдельные плоские mesh-узлы под Model, имена до 180 символов |
| `s`, `vn` | Разрывы и smoothing groups учитываются; нормали пересчитаны по геометрии. UV-швы могут давать дополнительные жёсткие границы, о чём сообщает отчёт |
| `mtllib`, `usemtl` | Пропущены с отчётом, файлы и URL не открываются |
| Vertex RGB, третья координата vt | Пропущены с отчётом |
| Линии/точки | Пропущены с отчётом; отсутствие поверхностей — ошибка |
| N-gon, вогнутый/неплоский quad, freeform | Отказ с номером строки; предварительно триангулируйте |
| Анимация, PBR, единицы измерения | Не переносятся |

Лимиты: 16 МиБ UTF-8, 300 000 записей каждой таблицы, 100 000 треугольников, 128 непустых групп, 16 384 символа в строке. Сетка проверяется доменным geometry validator; вырожденные треугольники отклоняются. Замкнутость не обязательна для просмотра, но последующий CSG требует корректного замкнутого solid. Исходный OBJ не сохраняется и никогда не исполняется.

Проверки: 17 parser/transaction/archive tests. Браузерный `qa/import-panel.obj` с намеренно отсутствующим MTL: отчёт → добавление → Undo → Redo → фокус объекта; доказательство `qa/obj-import.png`. Формат отделён от GLB и не меняет его контракт. Описание структуры OBJ: [Three.js OBJLoader](https://threejs.org/docs/pages/OBJLoader.html); используется собственный ограниченный parser, чтобы явно отклонять неподдерживаемые грани.

Отмена дополнительно проверена в браузере на локальном файле с 300 000 вершинами / 100 000 треугольниками: job завершился отменой, существующая панель осталась неизменной, результат не появился. Доказательство `qa/obj-cancel.png`; матрица совместимости видна до применения.
