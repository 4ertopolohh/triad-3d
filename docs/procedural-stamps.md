# Процедурные штампы — TASK-055

Документ 1.13.0 добавляет `Modifier.kind=stamp`. Строгая миграция 1.12 меняет только версию. Параметры: hole/dent/spike, center, направление normal, radius/depth, count 1–16, spread, seed uint32, mirror off/X/Y/Z. Любой штамп остаётся отдельным редактируемым генератором в упорядоченном стеке; native archive сохраняет параметры, TSX/GLB запекают вычисленную геометрию.

В модели выберите mesh и «Кисть штампов», затем форму, радиус и глубину/высоту. Кольцо показывает радиус на поверхности; клик создаёт одну атомарную операцию. Первичная постановка не зеркалируется автоматически; зеркало, повторения и начальное значение генератора редактируются в Inspector. Координаты локальные; нормаль курсора переводится обратным преобразованием нормалей и корректна при неравномерном масштабе.

Повторения детерминированно распределяются по диску в касательной плоскости, затем проецируются вдоль направления normal на исходную поверхность текущего этапа. Из всех пересечений выбирается ближайшее к предложенному центру, поэтому исходная точка не перескакивает на внешнюю часть нависающей геометрии. Фактическая ориентация берётся из нормали найденной грани. Поля «Направление проекции» меняют поиск поверхности, а не свободно вращают резак. Зеркало отражает центр и направление относительно локального origin. Промах любого повторения отклоняет всю операцию.

Отверстие — цилиндр с заданной глубиной внутрь, углубление — эллипсоид, шип — конус с 5% перекрытием основания. CSG выполняется последовательно в Worker. Самопересечения и неманифолдные входы проверяет Manifold; полное удаление объёма запрещено. До 50 000 входных треугольников на генератор; между raycast-проекциями управление возвращается UI, проверяется отмена. До 32 резаков с зеркалом. Ограничение защищает отзывчивость, это не заявленный универсальный предел производительности.

Общая проверка `checkedModifierChange` вычисляет кандидат целевого mesh и всех транзитивных активных Boolean-потребителей, включая удаление/отключение последнего штампа. Ошибка/отмена/устаревший проект сохраняют документ и историю. Идентификатор модификатора обязан принадлежать выбранному объекту и совпадать с типом действия. Этот же протокол используется массивами.

UV, группы материалов и авторские нормали CSG не сохраняются; видимый отчёт сообщает потери. Для вычисленной геометрии редактор и экспорт используют одинаковые нормали с порогом ребра 60°: плоские стенки не сглаживаются через острый край отверстия, округлые участки остаются сглаженными. Исходная доменная топология не меняется.

Проверки: реальный Manifold для отверстий/углублений/шипов; объём и повторяемость; native roundtrip/Undo/Redo; обновление и перестановка генераторов; проекция на сферу и точка под навесом; сохранение плоских нормалей; полный rollback удаления объёма и отказ зависимого стека; отмена ожидающего job; отказ несовпадающему владельцу. Эталон `qa/stamp-complex.triad3d` содержит зеркальные сквозные отверстия и группу шипов, воспроизводится `createStampGolden`.

Браузерная проверка: создание и редактирование штампа, затем открытие эталонного native archive в новой вкладке; WebGPU и WebGL2 без ошибок консоли. Снимки: `qa/stamp-complex-webgpu.png`, `qa/stamp-complex-webgl2.png`. Three.js 0.186.1, Windows, встроенный Chromium браузер; точная версия браузера не зафиксирована.

Профиль проекций (`qa/stamp-projection-profile.json`): 49 600 треугольников, 31 резак, 1,62 с, 31 обработка таймера, максимальный интервал 108 мс. Это измерение конкретной модели в Node 24.21.0 под Windows, не гарантия задержки на всех моделях: отдельный raycast синхронный.
