# Пакеты материалов (TASK-058)

Кнопка «Пакеты» сохраняет материалы проекта и PNG/JPEG/WebP/HDR/EXR в `.triadpack`. Это библиотечный профиль существующего версионируемого ZIP-контейнера: manifest, document и проверяемые SHA-256 ресурсы. Геометрия, анимация и история в пакет не входят. Вложенных ZIP нет; действуют лимиты и защита путей нативного архива.

Открытие проходит в отменяемом Worker. Каждый ресурс проверяется по заголовку, бюджету декодирования и фактическому декодеру. JPEG-пути нормализуются в `.jpg`. Перед применением показаны количества и диагностика. Одна транзакция добавляет весь пакет; отмена, ошибка, устаревшая ревизия или подмена проекта не публикуют частичные изменения. Undo/Redo работают со всем пакетом.

Совпадающие hash+MIME переиспользуют ресурс как из проекта, так и из ранее обработанной части пакета. Материалы получают новые ID и переназначенные ссылки. Их можно назначить из раздела «Материалы проекта и пакетов». Совпадающие названия получают суффикс «(пакет)».

Документ 1.9.0 добавляет необязательное `Asset.license` (1–16384 символа), сохраняемое в нативном архиве. Миграция 1.8→1.9 не меняет прежние данные. Поле лицензии при экспорте заполняет только отсутствующие сведения в копии; исходный проект не меняется. При дедупликации существующая лицензия сохраняется, конфликт показывается. Экспорт TSX ZIP включает лицензии ресурсов отдельными текстовыми файлами. Пользователь отвечает за достоверность введённых сведений; пакет не выдаёт лицензию автоматически.

Проверки: roundtrip, ссылки материалов, Undo/Redo и байты, dedupe, JPEG aliases внутри пакета, отмена, повреждённый hash, недопустимая геометрия, image dimension bomb до декодера и ошибка декодирования. Браузерный smoke: три материала и HDR → скачать → открыть → 0 новых ресурсов/3 материала → применить → Undo (0 импортированных материалов) → Redo (3); ошибок консоли нет.
