# Физика — TASK-053

Документ 1.12.0 хранит `physics` (до 128 тел модели), включая frozen snapshots. Строго проверенная миграция 1.11 меняет только версию. `SET_PHYSICS` атомарно проверяет ссылки и параметры, запрещает изменение заблокированных узлов, поддерживает Undo/Redo. Скорости, контакты, WASM-мир и накопленный шаг не сериализуются.

Inspector mesh задаёт включение, тип тела, box/sphere, размеры, массу, упругость и трение. Collider центрирован в origin и задаётся вручную: box использует полные локальные размеры XYZ, sphere — диаметр X и максимальный мировой масштаб. Он не выводится автоматически из Boolean/GLB/модификаторов. Пол — отдельный mesh со статическим телом; бесконечного невидимого пола нет.

Rapier 0.21.0 загружается лениво, WASM инициализируется при первом просмотре. Гравитация [0,−9.81,0], фиксированный шаг 1/60 с, CCD включён для dynamic. За кадр учитывается до 0.1 с: после приостановки вкладки пропущенное время отбрасывается. Один мир объединяет видимые экземпляры, контакты имеют отдельные scope/node ID. До 256 тел во всей сцене; превышение даёт диагностику. Ресурсы мира и EventQueue освобождаются при сбросе/dispose.

Dynamic управляет положением и вращением после timeline/правил; static сохраняет стартовую позу; kinematic получает целевую позу анимации. Конфликтующие правила и timeline отмечены в Inspector и export report. Изменение collider, масштаба, состава тел или документа пересоздаёт мир. Выключение preview, смена проекта или переход к инструменту редактирования восстанавливает авторскую позу. Вложенные тела и shear запрещены; dynamic/static требуют равномерного масштаба родителей. Кинематическое движение не гарантирует отсутствие пересечений: нельзя обещать collision-safe произвольную анимацию. Joints, soft bodies, concave/mesh colliders и baking симуляции не реализованы.

TSX/ZIP использует тот же адаптер. `playing` останавливает live physics, `speed` масштабирует шаг в пределах 0–4. Controlled `time` предназначен для детерминированного timeline: его наличие отключает stateful physics и сбрасывает мир; удаление `time` начинает новую симуляцию. Физическая перемотка не обещается. `onCollision({firstNodeId,secondNodeId,started})` получает начало/конец контакта после шага, без мутаций мира из callback. Экспортированные instance ID remapped. GLB сохраняет исходную позу и явно сообщает потерю физических тел; статический single-file требует ZIP.

Проверки: отскок сферы и contact begin/end; одинаковые позиции при 60/120 render frames за секунду; ограничение catch-up; kinematic target; disabled actor; строгий отказ неизвестным полям и duplicate IDs; native roundtrip, Undo/Redo и rollback отсутствующих/group ссылок; непрерывное падение при восстановлении render pose; отказ nonuniform parent. Браузер: сфера опустилась на статический пол, Inspector сохранил Y=3, переход к Move выключил simulation и восстановил старт; console errors отсутствуют. Снимки `qa/physics-before.png`, `qa/physics-settled.png`, `qa/physics-edit-restored.png`.

Контракты движка проверены по [официальной документации rigid bodies](https://rapier.rs/docs/user_guides/javascript/rigid_bodies/), [colliders](https://rapier.rs/docs/user_guides/javascript/colliders/) и [collision events](https://rapier.rs/docs/user_guides/javascript/advanced_collision_detection/).
